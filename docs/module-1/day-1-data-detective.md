## What I learned
This task reminded me of what data is and helped me to distinguish between the three main types of data: 
**quantitative data**, which is **measured or counted**, such as the number of orders received each day; 
**qualitative data**, which is **descriptive** and may include an **opinion**, such as a customer review; and an
**identifier**, such as the order ID **BAO125**, which identifies a particular order. 

It also improved my understanding of how data can be further classified: 

Data can be classified into three types based on how it is organised and stored.
**structured data:**  Structured data follows a predefined format, usually arranged in rows and columns, such as spreadsheets or databases, making it easy to search, sort and analyse; 

**semi-structured data:** Semi-structured data has some organisation through labels, tags or key-value pairs, such as JSON or XML files, but does not follow a rigid table format for example: `"order_id": "BAO125", "item": "Baobab drink", "quantity": 2`; and 

**unstructured data:**  Unstructured data has no predefined organisational format and includes information such as photographs, videos, audio recordings and written customer reviews, which often require additional processing before they can be analysed.
